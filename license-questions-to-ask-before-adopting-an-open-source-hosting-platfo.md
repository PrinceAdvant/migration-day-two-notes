# License questions to ask before adopting an open-source hosting platform

Open source hosting tools differ more in their licenses than in their features, and the license decides what you can do later.

Permissive licenses such as MIT and Apache 2.0 let you modify and run the tool privately without publishing changes. Copyleft licenses such as AGPL require you to share modifications if you offer the modified software to users over a network, which matters if you plan to build a product on top. Source available licenses may restrict commercial hosting entirely.

Check four things: the license file in the repository, whether some features are held back for a paid edition, whether a contributor agreement allows the license to change, and whether the project has more than one active maintainer.

None of these are reasons to avoid a tool, but they belong in the decision. A roundup of [open-source alternatives to Vercel](https://peon.sh/blogs/open-source-vercel-alternatives) lists several candidates.
